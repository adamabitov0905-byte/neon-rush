# NEON RUSH — публикация на GitHub Pages

В этой папке лежит всё, что нужно сайту. Git на компьютере не установлен,
поэтому заливать можно прямо через браузер — файлы перетаскиванием.

## Шаги (около 2 минут)

1. Открой https://github.com/new
2. Имя репозитория: `neon-rush`, тип **Public**, нажми **Create repository**.
3. На странице репозитория: **Add file → Upload files**.
4. Перетащи туда **всё содержимое этой папки**: `index.html`, `manifest.webmanifest`,
   `icon.svg`, папку `paks` и файл `.nojekyll` (в проводнике включи показ скрытых файлов,
   если его не видно).
5. Внизу нажми **Commit changes**.
6. В репозитории: **Settings → Pages**.
7. В блоке *Build and deployment*: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/(root)**, нажми **Save**.
8. Через минуту адрес будет такой: `https://ТВОЙ_НИК.github.io/neon-rush/`

## На iPhone

Открой ссылку в **Safari** → «Поделиться» → **На экран «Домой»**.
Запустится на весь экран, без адресной строки. Интернет нужен только
для первой загрузки (файл весит 1.4 МБ), дальше работает из кэша.

## Что важно знать

- На GitHub Pages **нет сервера**, поэтому сетевые гонки между устройствами там
  не работают — экран «Сеть» честно напишет, что нужен локальный сервер.
- Мультиплеер по-прежнему доступен дома: `start-lan.bat` рядом с игрой.
- Обновление игры: заново загрузить `index.html` в репозиторий (Add file → Upload files),
  GitHub Pages обновится сам за минуту.

## Файлы

| файл | зачем |
|---|---|
| `index.html` | вся игра (three.js внутри) |
| `manifest.webmanifest` | установка на телефон, полноэкранный режим |
| `icon.svg` | иконка |
| `paks/*.json` | текстур-паки (Огонь, Лёд, Кислота) — качаются и ставятся в настройках |
| `.nojekyll` | отключает обработку Jekyll, чтобы файлы отдавались как есть |
